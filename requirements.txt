GasFlow React frontend requirements

System requirements
- Node.js 20 or newer
- npm 10 or newer

Install dependencies
- npm.cmd install

Run locally
- npm.cmd run dev

Build production files
- npm.cmd run build

Preview production build
- npm.cmd run preview

Project dependencies are managed in package.json and locked in package-lock.json:
- @vitejs/plugin-react ^4.3.4
- vite ^6.0.5
- react ^18.3.1
- react-dom ^18.3.1
- lucide-react ^0.468.0
