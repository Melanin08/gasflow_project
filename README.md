# Zanzibar LPG Stores

React frontend for checking LPG ordering, store selection, delivery tracking, and admin/store operations for Fuoni, Bububu, and Mombasa gas stores in Zanzibar.

## Requirements

- Node.js 20 or newer
- npm 10 or newer

See `requirements.txt` for the same setup checklist.

## Installation

Install all frontend dependencies:

```bash
npm.cmd install
```

For a clean install from the lockfile:

```bash
npm.cmd ci
```

## Run The App

Start the React development server:

```bash
npm.cmd run dev
```

Build the production app:

```bash
npm.cmd run build
```

Preview the built app:

```bash
npm.cmd run preview
```

The app will print a local URL such as `http://127.0.0.1:4173/` or `http://127.0.0.1:5173/`.
